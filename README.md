# 🛒 ShopPro - Full Stack MERN E-Commerce Platform

A feature-rich E-Commerce Web Application built using the **MERN** Stack (MongoDB, Express, React, Node.js) along with Tailwind CSS for styling and Razorpay for payment integration.

---

## 🚀 Features

### 👤 Customer Features
- User Authentication (JWT-based Register/Login)
- Product Search, Category Filters & Sorting
- Dynamic Shopping Cart
- Seamless Checkout Process (COD / Online Payment)
- Order History & Profile Management

### 🛠️ Admin Panel
- Admin Dashboard with Sales & Analytics Overview
- Product Management (Add, Edit, Delete Products)
- Order Management (Update Order Status)

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, React Router, React Hot Toast
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT, Nodemailer
- **Payments:** Razorpay Integration
